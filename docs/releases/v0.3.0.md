# v0.3.0 — Versioned SQLite Data Layer

This Pre-release upgrades the local web application's record persistence from a flat-file default to a versioned SQLite repository while preserving the CLI and historical CSV contract.

## Demonstrable workflows

- Complete a browser calculation and receive a durable record ID and UTC creation time.
- Filter history by item-name prefix and profit/loss outcome.
- Switch between stable newest/oldest order and navigate bounded result pages.
- Import a compatible historical CSV into SQLite repeatedly without duplicate rows.
- Run the server in explicit CSV mode as an operational rollback.

## Engineering additions

- Context-aware repository boundary with atomic append and bounded query contracts.
- Ordered transactional schema migrations and query-pattern indexes.
- Canonical scaled-integer storage for existing three- and six-decimal domain values.
- CGo-free SQLite driver pinned to the latest release compatible with Go 1.21.
- Source-aware, no-side-effect CSV import with inserted/skipped reporting.
- Nullable ownership and session columns reserved for later authenticated data isolation.
- Paginated history API metadata and responsive browser controls.

## Verification

- `make check` passes, including JavaScript syntax validation, `go vet`, race-enabled tests, and both binary builds.
- The OpenSpec change passes strict validation.
- Repository tests cover migration repeatability, query indexes, canonical values, pagination, invalid input, dependency failure, and complete transaction rollback.
- Smoke tests cover SQLite creation, calculation persistence, filtered history, repeat CSV import, and CSV rollback mode.

## Compatibility and limitations

- Existing CLI behavior and compatible five-, seven-, and eight-column record CSV files remain readable.
- SQLite is the new web default; the previous behavior remains available with `--storage=csv --file <path>`.
- CSV import never edits or removes the source file.
- SQLite remains a local single-process database; authentication, multi-user isolation, managed backups, quotas, production observability, and public deployment remain future milestones.
- AI conversations remain transient and are not written to the calculation repository.
