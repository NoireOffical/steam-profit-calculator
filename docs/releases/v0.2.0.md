# v0.2.0 — AI Strategy Assistant MVP

This Pre-release adds the first tool-grounded AI vertical slice while preserving every deterministic workflow from v0.1.0.

## Demonstrable workflows

- Ask a natural-language question in the browser assistant panel.
- Let the model select market lookup, forward calculation, or target reverse-solving tools.
- Watch tool progress and inspect exact structured evidence.
- Receive a grounded explanation whose numeric tokens are checked against trusted tool output.
- Run the full browser workbench and CLI with AI disabled or unavailable.

## Engineering additions

- Replaceable model boundary and optional OpenAI Responses API adapter.
- Strict, allow-listed, read-only `lookup_items`, `calculate_profit`, and `solve_target` tools.
- Bounded model/tool loop with in-memory stateless item replay and `store: false`.
- SSE status, tool, evidence, answer-delta, completion, and safe error events.
- Versioned prompt, observable model settings, latency, token usage, and tool count.
- Citation and numeric grounding guard with a safe evidence-directed fallback.
- Thirty deterministic evaluation fixtures requiring no live API credential.
- Responsive conversation UI with disabled, loading, evidence, completion, and error states.

## Verification

- `make check` passed, including JavaScript syntax validation, `go vet`, race-enabled tests, and both binary builds.
- The OpenSpec change passed strict validation.
- Disabled-AI health, status, and deterministic calculation workflows passed local smoke tests.
- The complete assistant SSE/tool/evidence path passed with an injected fake provider.
- The OpenAI function-call and tool-output continuation contract passed HTTP-adapter tests.

## Compatibility and limitations

- Existing CLI commands, deterministic API payloads, and CSV schemas remain compatible.
- AI is disabled by default and requires a separately supplied model API key.
- Chat is single-turn, transient, and not persisted.
- Answer `delta` events currently chunk a completed provider answer rather than forwarding provider-native token deltas.
- A live-model smoke test is not included because no model API credential is stored in the repository.
- Database durability, authentication, quotas, production observability, backups, and public deployment remain future milestones.
