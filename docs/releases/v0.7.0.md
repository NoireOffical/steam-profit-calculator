# v0.7.0 — Provider-ready portfolio walkthrough

This Pre-release packages the SteamApis extension adapter and the current deterministic full-stack application into a GitHub-ready demonstration milestone.

## Demonstrated workflows

- The browser accepts one buy scenario with four target sell prices and calculates all monetary values through the trusted server-side engine.
- The calculation batch is persisted through the production JSON API into versioned SQLite storage.
- The browser filters the resulting durable history by item-name prefix.
- The README embeds a lightweight GIF; the GitHub Pre-release carries `steam-profit-demo.mp4` as the full-resolution H.264 recording.
- The normalized lookup boundary can select the built-in `steam_public` provider or the authenticated `steamapis` adapter without changing browser, CLI, API, assistant-tool, CSV, or SQLite contracts.

The recorded scenario uses only the versioned local seed dataset and a synthetic item name. It contains no account, credential, API-key, provider response, prompt, model output, or real trading data.

## Verification

- `make check`
- Browser JavaScript syntax validation through the repository quality gate
- Local browser smoke: load the production workbench, calculate four sell-price scenarios, confirm the result table, and filter the newly persisted SQLite rows
- Visual review of the README GIF and H.264 Release MP4
- Deterministic SteamApis adapter tests covering authentication, normalization, timeouts, invalid payloads, bounded `429` retry, safe errors, and no-side-effect failures

## Known limitations

- Steam's official public endpoint can rate-limit automated requests. The site then recommends configuring a supported third-party Steam Market Provider while calculation and history remain available.
- SteamApis and OpenAI remain optional, replaceable extensions. No temporary real SteamApis key or paid OpenAI key was used for this release, so live external-provider behavior is not claimed.
- The Railway site is a controlled single-replica reviewer demo with separately supplied credentials, not a public multi-tenant service.

## Upgrade and compatibility

- No calculation formula, CLI flag, HTTP schema, CSV schema, SQLite schema, or stored record changes are introduced by the showcase assets.
- `steam_public` remains the default lookup adapter. Enabling SteamApis requires server-side provider and API-key configuration only; rollback is an environment change or deployment of the prior immutable tag.
- Existing databases and CSV files require no migration.
