# v0.1.0 — Web Application Foundation

This Pre-release is the first demonstrable full-stack checkpoint for Steam Profit Calculator.

## Demonstrable workflows

- Run one embedded Go web application locally.
- Search normalized Steam Community Market item snapshots.
- Calculate and persist one or more forward profit scenarios.
- Reverse-solve a buy or sell price from a target metric.
- Review server-side CSV history in the browser.
- Continue using all existing CLI commands and historical CSV files.

## Engineering additions

- Standalone `steam-profit-server` binary.
- Same-origin embedded HTML, CSS, and JavaScript application.
- Versioned health, lookup, calculation, reverse-calculation, and history JSON routes.
- Stable success/error envelopes, request-size limits, unknown-field rejection, method enforcement, and baseline security headers.
- Handler and browser-asset tests, CI updates, and local run documentation.

## Verification

- Formatting and `go vet` passed.
- Race-enabled Go test suite passed.
- CLI and server binaries built successfully on the milestone commit.
- Browser-to-server lookup, calculation, and history workflow was smoke-tested locally.

## Compatibility and limitations

- No CLI argument or CSV schema migration is required.
- The application is local and single-user.
- Persistence remains CSV-backed.
- Authentication, rate limiting, database storage, AI assistance, and production deployment are not included.
